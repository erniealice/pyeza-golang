## [0.1.0-alpha] - 2026-06-15

UI framework foundation — the dependency root of the platform (zero monorepo imports).

### Added
- `HTMLRenderer`, `AppContext`, `AppOption`, `RouteRegistrar`, and the full `types`
  package (`PageData`, `TableConfig`, `SidebarConfig`, etc.).
- Go template component library, icon set, themes, and design axes.

### Note
- Supersedes the `v0.0.x-alpha` prerelease series with a uniform `v0.1.0-alpha`
  baseline across all platform modules.
